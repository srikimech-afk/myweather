# Simple Weather App
A minimal Next.js weather app using the free Open-Meteo geocoding and forecast APIs. No API key required.

## Local
1. Install Node.js 20+
2. `npm install`
3. `npm run dev`

## GitHub
Upload all files/folders in this project to the ROOT of your repository. Do not put package.json inside the app folder.

## Vercel
Import the GitHub repository in Vercel. Framework should detect as Next.js. Keep Root Directory as `./` and deploy. No environment variables are required.
